## 2. Table Specifications

### 2.1 User
Stores primary user registration and login credentials.
* **id** (UUID, Primary Key): Autogenerated.
* **username** (VARCHAR(255), Not Null)
* **email** (VARCHAR(255), Unique, Not Null)
* **passwordHash** (VARCHAR(255), Not Null)
* **createdAt** / **updatedAt** (Timestamp)

### 2.2 Project
Groups related workflows, configurations, and connections.
* **id** (UUID, Primary Key): Autogenerated.
* **name** (VARCHAR(255), Not Null)
* **description** (TEXT, Nullable)
* **ownerId** (UUID, Foreign Key $\to$ User.id): ON DELETE CASCADE.
* **createdAt** / **updatedAt** (Timestamp)

### 2.3 Workflow
Represents a visual API flow. The path combined with the HTTP method is unique per project.
* **id** (UUID, Primary Key)
* **name** (VARCHAR(255), Not Null)
* **path** (VARCHAR(255), Not Null): The relative endpoint path (e.g., `/products/:id`).
* **method** (VARCHAR(10), Not Null): e.g. GET, POST, PUT, DELETE.
* **nodes** (JSONB, Not Null): Serialized state of React Flow nodes (stores positional coordinates, labels, and parameters like code snippets, database queries, and field mappings).
* **edges** (JSONB, Not Null): Serialized state of React Flow edges.
* **isPublished** (BOOLEAN, Default: false): Indicates if the endpoint is active on the gateway.
* **projectId** (UUID, Foreign Key $\to$ Project.id): ON DELETE CASCADE.
* **createdAt** / **updatedAt** (Timestamp)
* **Constraints**: `UNIQUE(projectId, path, method)`.

### 2.4 WorkflowVersion
Maintains historical backups for rollbacks.
* **id** (UUID, Primary Key)
* **workflowId** (UUID, Foreign Key $\to$ Workflow.id): ON DELETE CASCADE.
* **versionNumber** (INTEGER, Not Null)
* **nodes** (JSONB, Not Null)
* **edges** (JSONB, Not Null)
* **changelog** (TEXT, Nullable)
* **createdAt** (Timestamp)

### 2.5 GitConfiguration
OAuth state and target repository linkage.
* **id** (UUID, Primary Key)
* **userId** (UUID, Foreign Key $\to$ User.id): ON DELETE CASCADE.
* **provider** (VARCHAR(50), Not Null): GITHUB or GITLAB.
* **accessToken** (TEXT, Not Null): Encrypted string.
* **refreshToken** (TEXT, Nullable): Encrypted string.
* **repositoryName** (VARCHAR(255), Not Null)
* **repositoryUrl** (VARCHAR(255), Not Null)
* **isActive** (BOOLEAN, Default: true)
* **createdAt** / **updatedAt** (Timestamp)

### 2.6 GatewayConfig
Fine-grained routing controls per workflow.
* **id** (UUID, Primary Key)
* **workflowId** (UUID, Unique, Foreign Key $\to$ Workflow.id): ON DELETE CASCADE.
* **requireJwt** (BOOLEAN, Default: false)
* **jwtSecret** (TEXT, Nullable): Custom JWT secret, encrypted.
* **rateLimitLimit** (INTEGER, Nullable): Maximum requests.
* **rateLimitWindow** (INTEGER, Nullable): Rate limiting window in seconds (e.g. 60s).
* **updatedAt** (Timestamp)

### 2.7 ExecutionLog
Audit logs and metric collection for gateway traffic.
* **id** (UUID, Primary Key)
* **workflowId** (UUID, Foreign Key $\to$ Workflow.id): ON DELETE CASCADE.
* **method** (VARCHAR(10), Not Null)
* **path** (TEXT, Not Null)
* **responseStatus** (INTEGER, Not Null)
* **latencyMs** (INTEGER, Not Null)
* **errorDetails** (TEXT, Nullable)
* **requestPayload** (JSONB, Nullable): Truncated header/body log.
* **createdAt** (Timestamp)

## 3. Database Indexing & Optimizations
To support real-time metrics dashboards and clean API gateway lookups under peak load, the following indices must be configured:

* **Route Lookup Optimization**:
  ```sql
  CREATE UNIQUE INDEX idx_workflow_route ON "Workflow" ("projectId", "path", "method");
  ```
  *Provides $O(1)$ lookup for the Gateway to match incoming routes to a Workflow definition.*

* **Log Dashboard Aggregation**:
  ```sql
  CREATE INDEX idx_logs_aggregate ON "ExecutionLog" ("workflowId", "createdAt", "responseStatus");
  ```
  *Improves query speed for throughput dashboards, line graphs, and success rate aggregations.*

* **Cascade Integrity**:
  Foreign Key indices on `projectId`, `workflowId`, and `userId` are managed natively to optimize nested join operations during data cleanups.
